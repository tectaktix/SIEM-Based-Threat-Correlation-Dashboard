# SIEM-Based Threat Correlation Dashboard 🚨

This beginner-friendly project shows how security teams detect suspicious activity by combining small clues — just like a detective.

## 💡 Why It Matters
Hackers don’t usually break in with one big move. They leave little signs (called "indicators of compromise"). Security dashboards (like those in SIEM tools) help us **connect the dots** and spot attacks early.

## 🧠 What It Simulates
- A fake "Threat Dashboard" that shows login failures, odd activity, and internal alerts
- Simple rules that trigger alerts
- Raw log data saved as `.json` so it's easy to learn from

## 📊 How It's Organized
- **alerts.json**: Simulated log data from a fictional small business server
- **alert-rules.md**: Describes what should raise concern (ex: 5 login failures in 5 minutes)
- **mock-dashboard.png**: A visual dashboard mockup to demonstrate alert correlation

## 👩‍💻 Great For:
- Students learning cybersecurity
- Entry-level SOC analysts practicing alert triage
- Tech support professionals curious about real-world monitoring
